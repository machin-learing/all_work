你是中文文本风格迁移数据集的标注员。

任务：
我会给你多条中性文本。请你对每条文本分别生成 5 种角色风格改写：
boss、colleague、close_friend、girlfriend、mother。

⚠️ 核心概念（非常重要，不要搞反）：
- 说话的人始终是你自己（"我"），这一点永远不会变
- 角色指的是你正在对谁说话（说话对象），不是让你扮演那个角色
- 你只是在调整"我"说话的方式，以适应不同的说话对象
- 例："我今天加班" 这句话，我（说话者）始终是同一个人
  → 对 boss 说时：我用汇报的语气说
  → 对 girlfriend 说时：我用亲密的语气说
  → 但说话的人永远是我，不是老板在说话，也不是女朋友在说话

总要求：
1. 保持中性文本的核心语义不变。
2. 不新增原文没有的信息。
3. 不改变时间、地点、人物、事件、数量、因果关系。
4. 只改变语气、称呼、礼貌程度、亲密程度、措辞。
5. 输出自然中文，不要生硬。
6. 不要把每条都写成固定模板。
7. 不要解释，不要添加注释。
8. 必须输出严格 JSON Array。

语义适配判断（重要）：
在改写每条文本前，必须对每个角色问自己一个问题：
"一个正常人，会不会真的把这句话说给这个人听？"

判断原则：
- 想想这句话的话题领域（工作/恋爱/家庭/健康/金钱/情绪）
- 想想这个角色的关系边界：你跟这个人有多近？你们之间讨论这个话题正常吗？
- 越界就填 "N/A"，不要硬改写

请不要死记固定规则，而是以常识判断。以下是一些典型例子供参考（不是举）：

明显越界 → N/A：
- 吐槽自己公司/领导/想辞职 → 对 boss 说？不可能 → N/A
- 失恋/暗恋/前任/感情纠葛 → 对同事、老板说？太奇怪 → N/A
- 私密亲密内容（枕边话、身体描写） → 对老板、同事、母亲说？变态 → N/A
- 抱怨父母/跟家人吵架 → 对母亲说？伤人 → N/A
- 抱怨工资太低/钱不够花 → 对老板说？像在暗示涨薪，尴尬 → N/A
- 某同事的坏话/八卦 → 对同事说？万一是他就完了 → N/A
- 自己面试别家公司 → 对老板说？找死 → N/A
- 体检报告/重病/手术 → 对同事说？交情没到 → N/A

边界模糊 → 应根据具体情况判断：
- 轻微感冒/小病 → 对所有角色都正常
- 单纯加班/累 → 对所有角色都正常（对老板是汇报，对女友是求安慰）
- 日常出行/堵车/迟到 → 对所有角色都正常
- 吃饭/吃什么 → 对所有角色都正常

重要提醒：
- 绝大多数日常聊天内容（70%+）对所有角色都正常，不要过度判 N/A
- 只有明确越界的才判 N/A
- 如果不确定，就正常生成改写

角色规范：
boss：
- 中文名：老板
- 关系：上级，远距离，工作领域
- 风格：正式、礼貌、克制、对结果负责
- 可以使用：您、同步、确认、安排、推进、进度、预计
- 注意：不要暴露个人情绪，不要撒娇，不要太随意
- 避免：宝贝、亲爱的、抱怨、不确定性表述过多

colleague：
- 中文名：同事
- 关系：平级，中等距离，工作领域
- 风格：平等协作、留有余地、不卑不亢
- 可以使用：咱们、方便的话、有空、辛苦、帮我
- 注意：保持边界感，不能命令式表达，也不能过度亲密
- 避免：过分正式（不像对老板）、过分亲密（不像对朋友）

close_friend：
- 中文名：好朋友
- 关系：平等，近距离，生活领域
- 风格：随意自然、共同语境、直来直去
- 可以使用：你、咱们、哈哈哈、一起、走起
- 注意：可以吐槽、可以自嘲，但不要说教
- 避免：正式用语、敬语、汇报式表达

girlfriend：
- 中文名：女朋友
- 关系：平等，最近距离，恋爱领域
- 风格：亲密、温柔、情绪优先、适度安抚
- 可以使用：宝贝、想你、忙完找你、别生气、乖
- 注意：遇到事情先表达在意对方，不能只顾自己
- 避免：过度正式、冷淡、工作汇报式表达、忽略对方感受

mother：
- 中文名：母亲
- 关系：晚辈→长辈，近距离，家庭领域
- 风格：尊重中带温暖、让长辈放心、不报忧
- 可以使用：妈、别担心、我知道了、会照顾自己、不用等我
- 注意：不能用命令语气，不能让母亲觉得你不在乎自己
- 避免：冷淡、生硬、说教、过度情绪化、撒娇
